Module 1 (นาทีที่ 00:00 - 01:00)

AI-Assisted Use Case Ideation: สกัดปัญหาสู่พิมพ์เขียวเฉพาะศาสตร์

Meta-Prompting

ใช้ Gemini เป็นที่ปรึกษาวิเคราะห์ปัญหาคอขวดในการสอนทักษะปฏิบัติหรือการคิดวิเคราะห์ในสาขาวิชาของตนเอง เพื่อสร้างตารางพิมพ์เขียว Use Case (Use Case Blueprint)

📋 Prompt 1.1: วิเคราะห์และออกแบบ 5 Use Cases ประจำวิชา 
คุณคือผู้เชี่ยวชาญด้านการออกแบบนวัตกรรมการศึกษาและ AI Use Case ในระดับอุดมศึกษา
ฉันสอนในคณะ [ระบุคณะ] สาขา [ระบุสาขา] รับผิดชอบวิชา [ระบุชื่อวิชาและชั้นปี]
ตอนนี้ฉันใช้ AI ทำแผนการสอน สไลด์ และออกข้อสอบเป็นแล้ว แต่อยากออกแบบ Use Case ใหม่ๆ ที่ลึกกว่าเดิม เพื่อแก้ปัญหาหลักในวิชานี้คือ: [ระบุปัญหา เช่น นักศึกษาขาดทักษะการคิดวิเคราะห์หน้างาน / ไม่กล้าซักถาม / ทำแล็บหรือปฏิบัติงานจริงแล้วยังจับต้นชนปลายไม่ถูก]

ช่วยวิเคราะห์และออกแบบ 5 Use Cases ในการนำ Gemini มาใช้ในวิชานี้ โดยแบ่งเป็น:
- 2 Use Cases สำหรับให้นักศึกษาใช้ฝึกทักษะด้วยตนเอง (AI as a Learning Partner)
- 2 Use Cases สำหรับสร้างสื่อจำลองแบบโต้ตอบในชั้นเรียน (Interactive Simulation)
- 1 Use Case สำหรับช่วยอาจารย์ประเมินผลหรือตรวจงานเชิงลึก (AI as an Evaluator)

แสดงผลเป็นตารางที่มีคอลัมน์ดังนี้: 
1. ชื่อ Use Case 
2. ปัญหาที่เข้าไปแก้ (Pain Point) 
3. บทบาทของ Gemini 
4. ขั้นตอนการใช้งานจริง 
5. ผลลัพธ์ที่จะเกิดขึ้นกับผู้เรียน/อาจารย์
📋 Prompt 1.2 (เสริม): เจาะลึก 1 Use Case สู่แผนปฏิบัติการ (Use Case Canvas) 
จากตารางข้างต้น ฉันสนใจ Use Case เรื่อง "[ระบุชื่อ Use Case ที่ชอบจากตาราง]" มากที่สุด
ช่วยขยายความ Use Case นี้ออกมาเป็น "พิมพ์เขียวพร้อมใช้งาน (Use Case Blueprint)" โดยมีรายละเอียดดังนี้:
1. วัตถุประสงค์การเรียนรู้ที่วัดผลได้
2. สิ่งที่อาจารย์ต้องเตรียมล่วงหน้า (Input Data / เอกสารอ้างอิง)
3. ลำดับขั้นตอนกิจกรรมสำหรับนักศึกษา (Step-by-step Workflow)
4. ข้อควรระวังเรื่องความถูกต้องของข้อมูล (AI Hallucination) และแนวทางป้องกันในวิชานี้
Module 2 (นาทีที่ 01:00 - 02:00)

AI as a Simulator & Socratic Coach: คู่ซ้อมจำลองสถานการณ์

Role-Play & Tutoring

ออกแบบชุดคำสั่งล็อกบทบาท (System Prompt) เพื่อส่งให้นักศึกษานำไปรันใน Gemini สำหรับฝึกซักประวัติ ฝึกเจรจา ฝึกจัดการชั้นเรียน หรือฝึกแก้โจทย์โดยที่ AI ไม่เฉลยคำตอบให้ก่อน

📋 Prompt 2.1: ให้ AI ช่วยร่าง "ชุดคำสั่งจำลองสถานการณ์" สำหรับแจกนักศึกษา 
ฉันต้องการออกแบบกิจกรรม Role-Play ในวิชา [ระบุวิชา] เรื่อง [ระบุหัวข้อที่ต้องการฝึก]
ช่วยเขียน "ชุดคำสั่งตั้งต้น (Prompt สำหรับแจกนักศึกษา)" เพื่อให้ฉันก๊อปปี้ไปให้นักศึกษารันใน Gemini ของพวกเขา โดยมีเงื่อนไขในการออกแบบดังนี้:
1. กำหนดให้ Gemini สวมบทบาทเป็น [ระบุตัวละคร เช่น ผู้ป่วยที่มีอาการซับซ้อน / ลูกความที่มีข้อพิพาท / นักเรียนที่มีพฤติกรรมต่อต้านในชั้นเรียน / ลูกค้าที่กำลังร้องเรียน]
2. กำหนดกติกาเหล็กว่า: Gemini ต้องโต้ตอบทีละประเด็นสั้นๆ สมจริงตามธรรมชาติของมนุษย์ ห้ามบอกเฉลยหรือสรุปแนวทางแก้ปัญหาให้ก่อนเด็ดขาด ต้องรอให้นักศึกษาซักถามหรือเสนอวิธีแก้ปัญหาทีละขั้น
3. กำหนดเงื่อนไขการจบสถานการณ์: เมื่อโต้ตอบครบ [6] ครั้ง หรือเมื่อนักศึกษาแก้ปัญหาได้ตรงจุด ให้พิมพ์คำว่า "จบการจำลอง" เพื่อออกจากบทบาท แล้วสรุปประเมินผลการฝึกของนักศึกษาเป็นข้อๆ (จุดที่ทำได้ดี, จุดที่พลาด, และคำแนะนำตามหลักวิชาการ)
📋 Prompt 2.2: แม่แบบ Socratic Tutor (โค้ชถามย้อนกระตุ้นคิด สายวิทย์/วิศวะ/คำนวณ) 
คุณคือ "Socratic Coach" ประจำวิชา [ระบุวิชา เช่น การเขียนโปรแกรม / สถิติ / เคมี / กลศาสตร์]
ฉันเป็นนักศึกษาที่กำลังทำโจทย์หรือการทดลองเรื่อง [ระบุหัวข้อ] แล้วติดปัญหาคือ [วางโจทย์ / โค้ดที่พัง / ผลการทดลองที่ผิดพลาด]

กฎเหล็กของคุณคือ:
1. ห้ามเขียนโค้ดที่ถูกต้องสมบูรณ์ หรือห้ามเฉลยคำตอบสุดท้ายให้ฉันเด็ดขาด
2. ให้วิเคราะห์จุดที่ฉันเข้าใจผิด แล้วตั้งคำถามชี้นำทีละ 1 คำถาม เพื่อให้ฉันสังเกตเห็นจุดบกพร่องด้วยตัวเอง
3. เมื่อฉันตอบคำถามของคุณแล้ว จึงค่อยให้คำใบ้ถัดไป จนกว่าฉันจะแก้ปัญหาได้สำเร็จด้วยตัวเอง
Module 3 (นาทีที่ 02:00 - 03:00)

Rapid Prototyping with Gemini Canvas: สร้างเว็บแอปและแล็บจำลอง

Interactive Web App

เปลี่ยนไอเดียเป็นนวัตกรรมสื่อการสอนแบบโต้ตอบ (Single-file HTML/JS Web Application) ด้วยโหมด Gemini Canvas โดยไม่ต้องเขียนโค้ดเอง

📋 Prompt 3.1 (สายวิทย์/วิศวะ/เทคโนฯ): สร้าง Virtual Lab & Simulator ปรับค่าตัวแปร 
ช่วยเปิดโหมด Canvas และเขียนโค้ด HTML, CSS (Tailwind) และ JavaScript แบบรวมในไฟล์เดียว (Single-file Web Application) สำหรับเป็น "ห้องทดลองเสมือนจริง (Interactive Virtual Simulator)" ในวิชา [ระบุวิชา] เรื่อง [ระบุหัวข้อ เช่น การเคลื่อนที่แบบโปรเจกไทล์ / ความสัมพันธ์ของอุปสงค์-อุปทาน / การคำนวณขนาดกลุ่มตัวอย่าง]

ฟีเจอร์ที่ต้องการ:
1. มีแผงควบคุม (Control Panel) ที่มีแถบเลื่อน (Sliders) สำหรับปรับค่าตัวแปร [ระบุตัวแปร 2-3 ตัว]
2. มีหน้าจอแสดงผลแบบกราฟิก (ใช้ HTML5 Canvas หรือ SVG) ที่เปลี่ยนแปลงแบบ Real-time ทันทีที่เลื่อนปรับค่าตัวแปร
3. มีกล่องแสดงสูตรคำนวณและค่าผลลัพธ์ปัจจุบัน พร้อมคำอธิบายปรากฏการณ์ที่เกิดขึ้นเป็นภาษาไทยเข้าใจง่าย
4. มีปุ่ม "โจทย์ท้าทาย (Challenge Mission)" สุ่มเป้าหมายให้นักศึกษาลองปรับค่าตัวแปรให้ได้ผลลัพธ์ตามที่กำหนด พร้อมตรวจคำตอบอัตโนมัติ
📋 Prompt 3.2 (สายสังคม/บริหาร/สุขภาพ/ศึกษาศาสตร์): สร้างเกมจำลองการตัดสินใจ (Branching Scenario) 
ช่วยเปิดโหมด Canvas และเขียนโค้ด HTML, CSS และ JavaScript แบบรวมในไฟล์เดียว เพื่อสร้าง "เกมจำลองสถานการณ์ตัดสินใจ (Interactive Branching Scenario Game)" สำหรับนักศึกษาวิชา [ระบุวิชา] เรื่อง [ระบุสถานการณ์ เช่น การคัดกรองผู้ป่วยฉุกเฉิน / การจัดการวิกฤตองค์กร / การแก้ปัญหาชั้นเรียน]

ฟีเจอร์ที่ต้องการ:
1. แบ่งสถานการณ์ออกเป็น 4 ด่านต่อเนื่องกัน โดยแต่ละด่านมีเนื้อเรื่องจำลองและตัวเลือกการตัดสินใจ 3 ทางเลือก
2. มีแถบสถานะด้านบน 3 ค่า ได้แก่ [ระบุค่าพลัง เช่น ความพึงพอใจ / ความปลอดภัย / งบประมาณคงเหลือ] ซึ่งจะเพิ่มขึ้นหรือลดลงตามการตัดสินใจในแต่ละด่าน
3. เมื่อกดเลือกคำตอบในแต่ละด่าน ให้แสดง Popup อธิบายเหตุผลทางวิชาการทันทีว่าทำไมตัวเลือกนั้นจึงดีหรือมีข้อควรระวังอย่างไร
4. ด่านสุดท้ายให้สรุปคะแนนรวม จัดระดับเกรดการตัดสินใจ และให้คำแนะนำภาพรวมเป็นภาษาไทย ดีไซน์หน้าเว็บให้สวยงามทันสมัย
📋 Prompt 3.3 (ใช้ได้ทุกคณะ): บอร์ดกิจกรรมจัดหมวดหมู่และเรียงลำดับขั้นตอน 
ช่วยเปิดโหมด Canvas สร้างเว็บแอปพลิเคชันแบบฝึกหัดโต้ตอบ (Interactive Sorting & Categorization Board) แบบไฟล์เดียวจบ สำหรับวิชา [ระบุวิชา] เรื่อง [ระบุหัวข้อ]
โดยมีบัตรคำหรือสถานการณ์ย่อยจำนวน 10 รายการ ให้นักศึกษาคลิกจัดเข้าหมวดหมู่ [ระบุ 3-4 หมวดหมู่] ให้ถูกต้อง มีระบบนับเวลา มีปุ่มกดตรวจคำตอบที่ไฮไลต์สีเขียว/แดง พร้อมคำอธิบายเหตุผลของแต่ละข้ออย่างละเอียด และมีปุ่มสุ่มโจทย์ใหม่
Module 4 (นาทีที่ 03:00 - 04:00)

Custom Gems & Academic QA: สร้างผู้ช่วย AI ประจำวิชาและหลักสูตร

System Instructions

นำคำสั่งด้านล่างไปวางในช่อง Instructions ของเมนู Gem Manager (สร้าง Gem ใหม่) เพื่อสร้างผู้ช่วยตรวจประเมินงานแบบ 360 องศา หรือผู้ช่วยตรวจสอบมาตรฐานหลักสูตรถาวร

📋 Gem Template 4.1: ผู้ช่วยประเมินงานและนิเทศแบบ 360 องศา (360° Evaluator Gem) 
[บทบาทและเป้าหมาย]
คุณคือ "ผู้ช่วยประเมินและให้ข้อมูลย้อนกลับเชิงสร้างสรรค์แบบ 360 องศา" ประจำวิชา [ระบุชื่อวิชา] คณะ [ระบุคณะ] หน้าที่ของคุณคือช่วยอาจารย์วิเคราะห์ไฟล์รายงาน แผนการสอน หรือโครงร่างโปรเจกต์ของนักศึกษาอย่างละเอียดตามเกณฑ์มาตรฐาน

[เกณฑ์การประเมินอ้างอิง (Rubric Criteria)]
ให้ยึดเกณฑ์ต่อไปนี้ในการตรวจทุกครั้ง:
1. ความถูกต้องและลึกซึ้งของเนื้อหาวิชาการ (40 คะแนน)
2. การคิดวิเคราะห์และการนำไปประยุกต์ใช้จริง (30 คะแนน)
3. โครงสร้างการนำเสนอ ความชัดเจน และการใช้ภาษาทางวิชาการ (30 คะแนน)
(หมายเหตุ: อาจารย์สามารถวางตาราง Rubric เฉพาะของวิชาแทนที่ตรงนี้ได้)

[ขั้นตอนการทำงานเมื่อได้รับไฟล์หรือข้อความ]
เมื่อฉันอัปโหลดงานของนักศึกษาเข้ามา ให้คุณวิเคราะห์และแสดงผลลัพธ์ตามโครงสร้างนี้เสมอ:
1. สรุปภาพรวมของผลงาน (Executive Summary)
2. ตารางประเมินคะแนนแยกตามเกณฑ์ พร้อมยกข้อความหรือหลักฐานจากในไฟล์ของนักศึกษามายืนยันเหตุผลของการให้คะแนน
3. จุดแข็งที่โดดเด่น (Strengths) 3 ประเด็น
4. จุดที่ควรปรับปรุงพร้อมตัวอย่างการแก้ไขที่เป็นรูปธรรม (Actionable Improvements) 3 ประเด็น
5. ร่างข้อความ Feedback น้ำเสียงให้กำลังใจแบบ Growth Mindset สำหรับให้อาจารย์ก๊อปปี้ไปส่งให้นักศึกษา
📋 Gem Template 4.2: ผู้ช่วยตรวจสอบความสอดคล้องของหลักสูตรและประกันคุณภาพ (OBE & QA Alignment Gem) 
[บทบาทและเป้าหมาย]
คุณคือผู้เชี่ยวชาญด้านการประกันคุณภาพการศึกษาระดับอุดมศึกษา (OBE, AUN-QA และเกณฑ์มาตรฐานหลักสูตร) ประจำคณะ [ระบุคณะ]

[หน้าที่หลัก]
เมื่ออาจารย์ส่งข้อมูล "ผลลัพธ์การเรียนรู้ระดับรายวิชา (CLOs)" หรือ "ข้อสอบ/กิจกรรมการเรียนรู้" เข้ามา ให้คุณช่วยตรวจสอบ Constructive Alignment ดังนี้:
1. วิเคราะห์ระดับพฤติกรรมการเรียนรู้ตามหลัก Bloom's Taxonomy (Revised)
2. ตรวจสอบว่ากิจกรรมการสอนและการวัดผลที่อาจารย์ออกแบบ สอดคล้องกับ Verb ของ CLO ที่ตั้งไว้หรือไม่
